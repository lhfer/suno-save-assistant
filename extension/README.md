# Suno 歌曲保存助手 0.3.0

保存自己的可播放 Suno 歌曲，后台静音处理，检查完整后自动下载。

## 安装

1. 解压发布包，并把整个文件夹放在长期保留的位置。
2. 打开 chrome://extensions，启用开发者模式。
3. 选择「加载已解压的扩展程序」，选择本文件夹（其中应直接包含 manifest.json）。
4. 刷新 Suno 页面。在歌曲旁点「保存」，或向插件粘贴歌曲链接。

已有旧版时，请先停用旧版，避免同时加载两份。后续更新保留同一扩展公钥，覆盖文件后重新加载。不要把安装目录当成临时下载文件夹清理。

## 使用

- 歌曲旁「保存」、插件保存当前歌曲、粘贴链接、右键链接、Option/Alt+Shift+S。
- 任务串行处理。关闭弹窗后仍继续；请保持 Chrome 打开。
- 播放器启动需要短暂显示一个静音任务页，随后自动回到先前页面。用户主动切走时不会抢回焦点。
- 输出为默认下载目录的 Suno 子文件夹中的 M4A / Opus 音频，不做 MP3 转码或音质提升。
- 完整性检查涵盖时间线、片段顺序、采样字节和总时长，Chrome 确认文件完成后才显示「已保存」。
- 短链与长链按实际歌曲去重。已保存文件存在时复用，文件已删除时允许重新保存。
- 重启或更新后可继续未完成任务；音频从头采集，不是断点续传。
- 弹窗底部可以备份任务元数据。备份含歌曲信息与文件路径，请按个人文件保管。

## 范围

只使用网页正常播放交给缓冲区的音频，不调用官方导出、下载计费或 WAV 生成接口，不提取播放密钥。适用于你拥有或有权保存且可正常播放的歌曲。项目与 Suno 官方无关联。

Chrome 120+。支持单音轨 fragmented MP4 / M4A；超过 64 MiB、格式不支持或完整性失败会明确停止。加速失败时，指定错误可自动用正常速度重试一次。耗时随网页与网络变化。

任务状态与最近记录仅保存在本地，不上传；没有远程统计服务。最近保留 30 首已保存记录、40 条已结束任务，最多 20 首待处理歌曲。
