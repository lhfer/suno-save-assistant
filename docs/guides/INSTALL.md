# 安装、更新与排查

## 选择正确文件夹

[下载最新 Release](https://github.com/lhfer/suno-save-assistant/releases/latest) 的扩展 ZIP，解压后选择直接包含 `manifest.json` 的 `suno-save-assistant` 文件夹。直接克隆仓库时选择 `extension/`。

请把文件夹放在长期保留的位置。Chrome 会继续从这里读取扩展文件，删除安装文件夹会使插件失效。

## 首次安装

1. 打开 `chrome://extensions` 并启用开发者模式。
2. 点击「加载已解压的扩展程序」，选择上述文件夹。
3. 可将「Suno 歌曲保存助手」固定到工具栏，刷新 Suno 页面。
4. 在歌曲旁点「保存」，或打开插件粘贴歌曲链接。

## 更新

完成或取消当前任务，备份需要保留的任务记录。用新版本覆盖安装目录中的文件，再点「重新加载」并刷新 Suno。固定公钥保持此公开版本后续更新的扩展身份；卸载扩展会删除 Chrome 存储中的记录。

从更旧、使用不同扩展身份的个人版本迁移时，不能假定历史自动共享。公开 ZIP 不包含任何迁移种子或私人历史。不要同时启用两份插件。

## 正常工作时

任务页在初始化时会短暂显示，全程标签页静音；随后返回先前页面。任务串行执行，关闭弹窗不会取消它们，但请保持 Chrome 打开。默认下载目录内会生成 `Suno/歌名-歌曲ID前8位.m4a`。

Chrome 重启、插件更新或重新加载后，未完成任务显示「待继续」。继续时从头重新采集；已完整落盘的下载会先检查是否可以直接复用。

## 遇到问题

| 现象 | 检查 |
| --- | --- |
| 没有保存按钮 | 确认插件启用，刷新 Suno 页面 |
| 长时间准备中 | 确认已登录且目标歌曲能正常播放；若提示需要播放，按提示打开任务页操作 |
| 保存失败 | 阅读任务错误；不要把残缺文件改名当作成功 |
| 找不到文件 | 点「在文件夹中显示」，并确认 Chrome 默认下载目录 |
| 另一款播放器不兼容 | 输出是 M4A / Opus，可使用支持该组合的播放器；插件不做 MP3 转码 |

报告问题请附版本、复现步骤和脱敏错误，勿上传私人歌曲链接、登录信息或完整任务备份。
