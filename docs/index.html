几个你可能想知道的细节。

会使用官方导出额度吗？

插件读取网页正常播放的音频缓冲区，不调用官方导出、下载计费或 WAV 生成接口。适用于你拥有或有权保存且在网页上可正常播放的歌曲。

为什么会短暂切换标签页？

Chrome 需要让新任务页先初始化音频。插件会短暂显示静音任务页，随后自动返回；你主动切走时，它不会抢回焦点。

保存的文件是什么格式？

M4A 容器中的 Opus 音频，位于默认下载目录的 Suno 文件夹。插件不做音质提升或 MP3 转码。

中断后能接着保存吗？

任务记录会保留，重开 Chrome 后可以继续。未完成的音频会从头采集；已完整保存的文件先检查是否可复用。
